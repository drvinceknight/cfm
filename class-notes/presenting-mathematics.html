Presenting Mathematics

In class meeting

Give a presentation.

Specifically present ertai version 0.0.2 (a library specifically built for this purpose).

After the presentation, if there are any questions about the topic, answer them.

After that, give an overview of the principles of presentation: https://vknight.org/pop/.

Bring back for a group discussion.

Communications

Before class

Send the following message before class:

Hi all,

In tomorrow's class I will give an example 15 minute presentation.

After the presentation and any questions you might have we will discuss
the following principles of presentation: https://vknight.org/pop/

Note that as part of my presentation I will give you another example of
an entire project (the other examples having been discussed in class and
in the notes).

Please get in touch if I can assist with anything,
Vince
