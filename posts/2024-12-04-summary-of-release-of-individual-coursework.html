Some points that came up during our discussion include:

  • I'd recommend before submitting that you restart and run your entire kernel to ensure the code works.
  • You should not delete anything in the cells.
  • Read the question carefully: if the question asks you to output something, make sure you do. If it asks you to create a variable with a specific name make sure you do.
